About CyberAware AI

🏆 Project Name

CyberAware AI — Cybersecurity Awareness Chatbot for Beginners

🎯 Objective

Bridge the cybersecurity knowledge gap for everyday internet users. Most people lack awareness of basic digital threats — CyberAware AI provides instant, jargon-free education to help beginners protect themselves online.

✨ Features

  • 💬 Interactive AI-powered chat interface
  • 🛡️ Structured responses: Explanation, Why it Matters, How to Stay Safe, Tips
  • 📦 Demo Mode with built-in knowledge base (11+ topics)
  • 🎣 Quick suggested questions for instant learning
  • 📋 Copy response to clipboard
  • 📱 Fully responsive — works on all devices
  • ♿ Accessible with ARIA labels and keyboard navigation

🛠️ Technology Stack

  • 🌐 Frontend: HTML5, CSS3, Vanilla JavaScript (ES2022)
  • 🤖 AI Backend: IBM Granite 3.1 8B Instruct via Hugging Face Inference API
  • 🔗 Proxy: Node.js HTTP server (CORS bypass)
  • 🎨 Typography: Inter + Share Tech Mono (Google Fonts)

🤝 IBM Granite AI Usage

CyberAware AI uses the IBM Granite 3.1 8B Instruct model (ibm-granite/granite-3.1-8b-instruct) — the same model family as IBM Bob — via the Hugging Face Inference API. The model is instructed to return structured JSON matching a predefined schema, ensuring consistent, high-quality responses. When the AI is unavailable, a curated local knowledge base activates as a Demo Mode fallback.

🔭 Future Scope

  • 🗣️ Voice input/output for accessibility
  • 🌍 Multi-language support (Hindi, Spanish, French)
  • 📊 Quiz mode to test cybersecurity knowledge
  • 📰 Live threat intelligence feed integration
  • 🏫 School/college curriculum module integration
